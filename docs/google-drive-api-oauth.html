给自己程序接 Google Drive API：一次授权长期复用

整理于 2026-10-26。目标：登录一次拿到授权，之后程序自动续期，不用反复登录；授权文件只留自己手里。

一、原理：登录一次，为什么以后不用再登录

谷歌用的是 OAuth 2.0。第一次登录并点同意后，程序拿到两个东西：

  • access token（短期，约 1 小时过期）：真正拿去调 API 的凭证。
  • refresh token（长期）：access token 过期后，程序用它换新的 access token，全程不用你再登录。这就是 offline 模式。

所以“一次授权长期复用”是标准用法，不是旁门左道。但“永久”要打个折，refresh token 会在以下情况失效：

  • 超过 6 个月没用过，谷歌会收回。
  • 项目处在“测试”状态，refresh token 7 天就过期（最常见的坑，见第三节）。
  • 你在谷歌账号的第三方访问权限页里手动撤销。
  • 改了权限范围（scope），要删掉旧 token 重新授权。

二、第一步：建项目、开 API

  1. 浏览器打开 Google Cloud 控制台（要能访问谷歌）。
  2. 新建一个项目，名字随便起，比如 my-drive-tool。
  3. 左侧菜单 → API 和服务 → 库，搜 Google Drive API，点启用。

三、第二步：配 OAuth 同意屏幕（关键一步别省）

  1. API 和服务 → OAuth 同意屏幕，User Type 选“外部”。
  2. 应用名称、支持邮箱、开发者邮箱填你自己的。
  3. 点“发布应用”，设为正式版。不发布的话项目处在测试状态，refresh token 7 天过期，过几天又要重新登录。
发布后首次登录可能出现“此应用未经 Google 验证”的提示，点“高级”→“前往应用（不安全）”继续就行。个人自用没问题，这只是因为没走谷歌的正式验证流程，不影响你自己用。

四、第三步：建 OAuth 客户端

  1. API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID。
  2. 应用类型选“桌面应用”，创建后下载 JSON 文件，存为 client_secret.json。
  3. 这个文件含 client_id 和 client_secret，保管好，别进代码仓库、别公开。

五、第四步：跑一次授权，拿到 token.json

装库并跑下面这段（Python）：

pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib
import os.path
from google.auth.transport.requests import Request
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow

SCOPES = ["https://www.googleapis.com/auth/drive"]
creds = None
if os.path.exists("token.json"):
    creds = Credentials.from_authorized_user_file("token.json", SCOPES)
if not creds or not creds.valid:
    if creds and creds.expired and creds.refresh_token:
        creds.refresh(Request())
    else:
        flow = InstalledAppFlow.from_client_secrets_file("client_secret.json", SCOPES)
        creds = flow.run_local_server(port=0)
    with open("token.json", "w") as token:
        token.write(creds.to_json())

跑起来后浏览器会打开谷歌登录页，登录并点允许，当前目录就生成 token.json，这就是你要的授权文件。上面这段逻辑每次启动都跑一遍：token 有效直接用，过期了自动用 refresh token 换新的并写回，不用你再登录。

六、第五步：程序里调用 Drive API

列文件

from googleapiclient.discovery import build
service = build("drive", "v3", credentials=creds)
files = service.files().list(pageSize=10, fields="files(id,name)").execute()
print(files)

上传文件

from googleapiclient.http import MediaFileUpload
media = MediaFileUpload("本地文件路径", resumable=True)
created = service.files().create(
    body={"name": "云盘上的文件名"},
    media_body=media,
    fields="id",
).execute()
print("上传成功，文件 ID:", created["id"])

更多操作（下载、搜索、建文件夹、移动、复制、删除、分享、改权限）都在同一个 service.files() 下面，方法名和官网 API 文档一一对应。

七、scope 怎么选

scope权限适合
drive.readonly只读只要下载、备份、列目录
drive.file只操作本程序创建的文件程序自己的上传下载，不想碰盘里别的文件
drive全部文件读写要管理整个云盘时用

按需选最小的。改 scope 要删掉 token.json 重新跑一遍第五步。

八、注意事项

凭证保管：client_secret.json 和 token.json 都是凭证。token.json 尤其不能给别人——谁拿到它，谁就能操作你的云盘。别进 git、别公开、别发聊天。
  • 多台设备：API 不绑定设备，认的是项目加凭证，没有设备数量上限。最干净是每台设备各跑一遍授权；也可以把 token.json 安全地拷过去，但别明文同步。配额是按项目共享的，多台设备并发一起算，要节流。
  • 程序跑在没浏览器的服务器上：在有浏览器的电脑上跑一次授权，再把 token.json 安全地拷到服务器（别走公开渠道）。
  • 失效重跑：长期不用（6 个月）或手动撤销后 refresh token 失效，重新跑一遍第五步即可。
  • 撤销：在谷歌账号的第三方访问权限页里撤销授权，所有用这个凭证的设备就都断了，适合设备丢失或换人时用。
  • 配额：默认项目级配额够个人用；大批量操作注意节流，别一下并发几百个请求。

九、如果你只是要同步文件，不用写程序

上面这套是给自己写程序准备的。如果只是要在电脑和云盘之间同步文件，不用走 Cloud 项目，直接用免费开源的 rclone：装好后跑 rclone config，按提示在浏览器里登录同意一次，授权文件存在本机 rclone.conf 里，同样长期有效。

说明：本文档只整理 Drive API 授权的操作步骤，不含任何密码、密钥与登录凭证。控制台菜单名字可能因版本和语言略有不同，以实际页面为准。
