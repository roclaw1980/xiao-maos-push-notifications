贴纸质检系统部署方案

Windows 本机版 · 2026-10-15 · 小毛大管家

一、这套东西是干嘛的

上传两张图——素材图（标准）和成品图（待检），系统做两层检查：

  • OpenCV（本地免费）：把两张图对齐，算相似度，框出差异区域。它是"尺子"，给确定数字。
  • Jev 1.14（云端 API，要 key）：判断有没有瑕疵、瑕疵分哪类、质量打 1–5 分、框出瑕疵位置。它是"裁判"，做语义判断。
分工一句话：OpenCV 找"哪里不一样"，Jev 判断"这个不一样算不算瑕疵"。比如模切毛边是正常工艺，印刷重影才是瑕疵——机器分不清的，Jev 能分。

二、要准备什么

  • Windows 电脑一台，CPU 就行，不用显卡
  • Python 3.12（去 python.org 官网下，安装时勾选 Add python.exe to PATH）
  • Jev API key（去 typesafe.ai 后台拿，你之前申请过，找一下）
  • 代码包 jev-qc-win.zip（已发你 Telegram）

三、安装步骤

第 1 步：装 Python

官网下载 3.12 安装包，一路下一步，记得勾选 Add to PATH。装完打开 cmd 输入 python --version，显示版本号就是好了。

第 2 步：装依赖库

打开 cmd，执行：

pip install opencv-python scikit-image pillow requests gradio

大概下载 200MB，几分钟。

第 3 步：解压代码包

把 jev-qc-win.zip 解压到比如 D:\jev-qc，里面有 5 个文件：compare.py、jev.py、app.py、start.bat、README.txt。

第 4 步：填 key

右键编辑 start.bat，把 你的key填这里 换成你的 Jev API key，保存。

四、运行

双击 start.bat，等几秒，浏览器打开 http://127.0.0.1:7860，页面出来就是成功了。

测试：左边传素材图，右边传成品图，点"开始质检"。

想在手机上测：把 app.py 里 share=True 保持不动，启动后控制台会给一个 https://xxxx.gradio.live 公网地址，手机浏览器打开就能用。

五、怎么看结果

指标含义
SSIM 相似度越接近 1 越像。同一张图对自己是 1.0
严重差异像素占比差异大的像素占全图的比例，超过 0.5% 就值得看一眼
差异区域（红框图）OpenCV 框出的差异位置
Jev：瑕疵概率成品图有印刷瑕疵的概率
Jev：瑕疵分类无瑕疵 / 污点 / 划痕 / 缺墨 / 色差 / 错位
Jev：质量打分1–5 分，1=无法出货，5=完全一致
Jev：瑕疵框模型认为瑕疵在图里的位置

六、费用

  • OpenCV：免费，本地跑
  • Jev：$0.042 / 百万 token，一张图几厘钱，一百张几毛钱

七、注意事项

先验证再进管线。Jev 的图像和 box 功能是实验性的（官方原话"还没达到生产标准"），box 没有"找不到"这个答案——图没问题时它也可能硬框一个。建议先拿 20 张已知良品 + 20 张已知瑕疵品跑一轮，看准不准再决定。
  • Jev 接口是按官方文档写的，还没拿真实 key 跑过。第一次跑如果报错，把错误信息原文发我，我来修。
  • 拍成品图时尽量跟素材图同角度、同光线，减少误报。
  • 代码里 0.5% 的阈值可以根据你的实际情况调，compare.py 里改 bad_ratio 的判断。
