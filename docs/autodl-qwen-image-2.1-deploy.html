AutoDL 上部署 Qwen-Image 2.1

RTX 5090 32GB · ComfyUI 方案 · 部署+使用一次讲清

一句话分工

你在 AutoDL 控制台点开机，把 SSH 登录地址和密码发给我；剩下的部署、出图全我来。用完我 SSH 关机——开机只能你点，关机我可以代劳。

一、开机前你准备什么

  1. AutoDL 控制台 → 租用实例 → 机型选 RTX 5090 32GB。
  2. 镜像选 PyTorch 2.x + CUDA 12.x（Ubuntu 22.04）的基础镜像，别选已经装好 ComfyUI 的整合包（版本旧，2.1 跑不起来）。
  3. 点开机，把实例的 SSH 登录指令和 root 密码发给我。

二、部署步骤（我 SSH 上去做）

1. 装最新 ComfyUI

git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI && pip install -r requirements.txt

Qwen-Image 2.1 要新版 ComfyUI 才认，老版本会报错。

2. 下三件套模型（走国内镜像加速）

export HF_ENDPOINT=https://hf-mirror.com
放的位置文件
models/diffusion_models/qwen_image_2.1_int8_convrot.safetensors
models/text_encoders/qwen3vl_8b_fp8_scaled.safetensors（必须是 8B 版，别下成别的尺寸）
models/vae/qwen_image_2.1_vae_bf16.safetensors

三个都从 Comfy-Org 官方仓库拿。模型放 /root/autodl-tmp 数据盘，别放系统盘。

3. 暴露 ComfyUI 端口

ComfyUI 默认跑在 8188 端口，在 AutoDL 控制台 → 自定义服务 → 把 8188 暴露出来，你就能在浏览器里打开操作界面了。

三、使用方案

文生图

用官方模板 image_qwen_image_2_1_t2i，推荐参数：

  • 采样器：Euler + beta
  • 步数：30
  • CFG：3 – 3.5

图生图 / 编辑图

用官方模板 image_qwen_image_2_1_image_edit，一次最多塞 10 张参考图，参数同上。

出图速度参考

5090 上 1024 分辨率单张通常在几十秒内（以实际跑的为准）。

四、省钱要点

  • AutoDL 只有「运行中」才按小时计费，关机不花钱。
  • 关机后数据保留 15 天，连续关机超 15 天实例会被释放，模型要重下。
  • 用完就关机：你可以直接在控制台点，或者跟我说一声我 SSH 关。
