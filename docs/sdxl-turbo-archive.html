关键技术结论（留给后人）

  • VAE dtype 坑（torch 2.11+）："Input type (Half) and bias type (float)" 报错。修复：每次推理前把 VAE 参数逐个对齐到 fp16（_fix_vae_dtype() 写进 t2i/i2i 函数开头，单次修复不 sticky）。
  • Gradio 6.30 文件组件 bug：gr.Image / gr.File 经 API 传入后服务端产生空张量（"cannot reshape tensor of 0 elements"），官方 gradio_client 也一样。绕开方案：图片输入改 gr.Textbox 传 base64 data URL，函数内直接解码，不经过文件系统。
  • 前端直传：自建 HTML 页用 FileReader 把用户选图转 data URL 直传，不走 /upload；绕开被墙的 AWS CDN（Gradio 默认前端在国内打不开）。
  • t2i 返回图实际是 WebP（文件名带 .png），下载处理时先验真实格式。
  • 未解边角问题：t2i 生成的图再做 i2i 会报空张量错（转真 PNG/JPEG 仍失败，原因未明）；用户传真机照片 i2i 正常。
  • 会话生存规律：免费 T4 无 40 分钟硬上限，是高峰期抢占——北京时间凌晨（美东下午）易被回收，上午（美东深夜）稳定；长任务排北京时间上午。
  • 依赖：pip install -q --upgrade diffusers gradio + transformers accelerate，卸载预装旧 torchao；实测 torch 2.11.0+cu128、diffusers 0.41.0、gradio 6.30.0。
