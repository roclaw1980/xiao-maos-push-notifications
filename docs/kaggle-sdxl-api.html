网页用法（最简单）

打开上面地址，两个页签：

  • 文生图：填英文提示词，选尺寸，点"生成"。
  • 图生图（参考图）：上传一张参考图，填英文提示词描述要改成什么，拖"改动强度"滑杆（默认 0.6，越大越不像原图），点"生成"。

API 用法

1. 文生图 /t2i（推荐 gradio_client）

pip install gradio_client
from gradio_client import Client

client = Client("https://8009eaf5ac77855168.gradio.live")  # 换成当前地址

img_path, info = client.predict(
    prompt="a cat astronaut floating in space, digital art",
    width=1024,      # 512 / 768 / 1024
    height=1024,     # 512 / 768 / 1024
    seed=-1,         # -1 = 随机；填固定数字可复现
    api_name="/t2i",
)
print(img_path)  # 生成图已下载到本地的路径
print(info)      # 如 seed=777

2. 图生图 /i2i（重点：gradio_client 传图有 bug，请用 REST）

为什么不用 gradio_client 传图？实测 gradio_client 2.7.2 传本地图片文件有 bug：传字符串路径时文件根本没上传、服务端报"需要图片数据"；传 Path 对象直接报"不可序列化"。这是客户端库的问题，服务端接口本身是好的。所以图生图走下面三步 REST 调用。
1上传参考图，拿到服务端路径 
import requests

base = "https://8009eaf5ac77855168.gradio.live"  # 换成当前地址

with open("ref.jpg", "rb") as f:
    up_path = requests.post(
        base + "/gradio_api/upload",
        files={"files": ("ref.jpg", f, "image/jpeg")},
        timeout=60,
    ).json()[0]
print(up_path)  # 如 /tmp/gradio/xxxx/ref.jpg
2发起图生图任务，拿到事件 ID 
event_id = requests.post(
    base + "/gradio_api/call/i2i",
    json={"data": [
        {"path": up_path},              # 第 1 步拿到的路径
        "turn the cat orange",          # 英文提示词：描述要改成什么
        0.6,                            # 改动强度 0.1~1.0，越大越不像原图
        -1,                             # seed，-1 = 随机
    ]},
    timeout=60,
).json()["event_id"]
3等结果（SSE 流），拿到生成图下载地址 
import json

r = requests.get(f"{base}/gradio_api/call/i2i/{event_id}",
                 stream=True, timeout=300)
for line in r.iter_lines():
    if line.startswith(b"data: "):
        out = json.loads(line[6:])
        # out = [图片信息, "seed=777 strength=0.6"]
        print("下载地址：", out[0]["url"])
        print("信息：", out[1])
        break

# 把图下到本地
img = requests.get(out[0]["url"], timeout=60).content
open("result.webp", "wb").write(img)
实测通过：参考图（宇航员猫）+ "the cat is now an orange tabby cat" + 强度 0.6 → 生成橘猫宇航员，约 8 秒。

参数说明

参数说明
prompt英文提示词。文生图：描述画面；图生图：描述"要改成什么"。
strength仅图生图。0.1～1.0，改动强度；0.6 是常用值。越小越接近原图，越大越放飞。
seed随机种子。-1 每次随机；固定数字可复现同一张图。
width / height仅文生图。512 / 768 / 1024 三档；图生图固定输出 1024×1024。

画质与适用边界

  • SDXL-Turbo 是"速度换画质"的蒸馏版：中等偏上，4 步出图。
  • 舒适区：卡通、粗线条、大色块（比如 1k 贴纸图）完全够用。
  • 短板：细节偏肉、画不出文字、复杂构图容易崩。
  • 要更精细：以后可上 SDXL 完整版或 Flux（待定二期）。
